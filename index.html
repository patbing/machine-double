        How it works
        
    
          
  • The real machine is plain JavaScript in this page: exact BigInt arithmetic, a key-value map, and small versions of the coreutils.
    • 
          
  • Each model gets the machine's manual and the session so far, and must print what the machine would print. Nothing else.
    • 
          
  • Outputs are compared line by line after collapsing spaces. A slip is any line that differs.
    • 
          
  • Dream shows each model its own earlier answers, so it lives in the world it imagined. Coached shows it the real outputs.
